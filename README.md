# Hotel Management Console Application

A Spring Boot console-based hotel management system developed with Java, Spring Boot, Spring Data JPA, Hibernate, and MySQL.

---

# Features

## Client Management

- Add client
- Show all clients
- Delete client
- Email uniqueness validation
- Confirmation before deletion

## Room Management

- Add room
- Show all rooms
- Delete room
- Room availability status

---

# Technologies Used

- Java 17
- Spring Boot 4
- Spring Data JPA
- Hibernate
- MySQL
- Lombok
- Maven
